# Syed Affan Ali — Portfolio

A dependency-light static portfolio built for GitHub Pages.

## Preview locally

Open `index.html` directly in a browser, or serve the folder with any static file server.

## Publish with GitHub Pages

1. Create a GitHub repository and upload the contents of this folder to its root.
2. Open **Settings → Pages** in the repository.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.

GitHub will provide the public URL after the first deployment completes.

## Personalize further

- Update the LinkedIn URL in `index.html` if the final public profile URL differs.
- Replace `assets/docs/Syed_Affan_Ali_CV.docx` whenever the resume changes.
- Add GitHub or live-demo links to project cards once those URLs are available.
